# Markaz_Islamic_Web

Planning documentation and a Phase 01 technical foundation for an independent, unofficial school website concept. The starter application is an engineering proof of the approved stack; it is not a complete school website and does not imply school authorization or approval to publish.

## Scope

The planning direction is a React and TypeScript, static-first information site with 14 main pages, English, Kiswahili and Arabic, full Arabic RTL, no CMS, no application database, and no student or parent portal. Selected UI components remain candidates pending implementation tests.

## Evidence and publication

The private local school research, source registers, media, and records are not included in this repository. The starter app uses clearly labeled technical sample copy and contains no approved school claims or school media. Verify facts against authorized, current evidence and obtain approvals before publication. Do not include identifiable pupil media, credentials, session files, or private records.

## Work gates

Work only within the explicitly authorized phase. Phase 01 foundation work is present under `website/`; later product-page implementation, deployment, commit, push, or publication still require the relevant explicit approval.
