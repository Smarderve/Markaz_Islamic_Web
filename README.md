## Scope

The planning direction is a React and TypeScript, static-first information site with 14 main pages, English, Kiswahili and Arabic, full Arabic RTL, no CMS, no application database, and no student or parent portal. Selected UI components remain candidates pending implementation tests.

## Evidence and publication

The private local school research, source registers, media, and records are not included in this repository. The public documents therefore do not serve as factual source material for school claims. Verify facts against authorized, current evidence and obtain approvals before publication. Do not include identifiable pupil media, credentials, session files, or private records.
