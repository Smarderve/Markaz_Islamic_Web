# Amiri font files

- Project: [Amiri by Alif Type](https://aliftype.com/amiri)
- Source release: [Amiri 1.003](https://github.com/aliftype/amiri/releases/tag/1.003)
- Files used: `Amiri-Regular.ttf` and `Amiri-Bold.ttf`
- License: SIL Open Font License 1.1; the original `OFL.txt` is included here.
- Font files are self-hosted without modification. The regular text face is used for Arabic interface and body copy; the Quran-specific font variants are not used.
