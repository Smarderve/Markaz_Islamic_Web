## Components written from scratch for Markaz

The homepage's word entrance and results reveal are original Markaz wrappers using the MIT-licensed Motion for React runtime. They do not contain React Bits source. The earlier Aceternity-derived Direction Aware Hover file has been removed and is not part of the application.

The official [React Bits license](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) is MIT plus Commons Clause; its text prohibits redistribution of its components themselves. Aceternity's [published terms](https://ui.aceternity.com/terms) prohibit copying and redistributing site material, and its [license page](https://ui.aceternity.com/licence) prohibits redistributing item source files. No React Bits or Aceternity component source is included in the public source change set.
