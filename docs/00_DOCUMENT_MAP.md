# Public Documentation Map

Read [AGENTS.md](../AGENTS.md) before project work. Load only the task-relevant specifications and the approved phase instructions.

## Authority and precedence

1. Current explicit user decisions.
2. Current authorized school sources and publication permissions, held outside this public repository.
3. Normative project specifications in this repository and an explicitly approved phase.
4. Historical/reference design snapshots under docs/reference/.
5. General inspiration and agent suggestions (not evidence about the schools).

This public documentation copy intentionally excludes private research, source registers, local media, and unpublished school records. Do not infer or invent school facts from the design specifications.
