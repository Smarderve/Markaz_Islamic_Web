# Local Research and Media Exclusion

The owner's local project contains research notes, source records, school-media files, and other working materials that are intentionally not included in this public repository. Their local availability does not grant publication rights.

Use only evidence and media that have been separately authorized for the intended use. Do not copy local research, source registers, pupil imagery, credentials, session files, or private records into this repository. The owner must review any proposed public evidence package separately.
