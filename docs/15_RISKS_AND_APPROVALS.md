# Risks and Approvals

This is a generic approval framework. It does not disclose the private project research inventory or represent that any school approval has been received.

| Area | Required review before public use |
|---|---|
| Institutional identity and affiliation | Confirm names, relationship, branding authority, and scope |
| Factual claims and history | Verify each claim against current authoritative evidence |
| Results and achievements | Confirm source, year, attribution, and any necessary consent |
| Contacts and admissions | Obtain current approved information |
| Facilities and programmes | Confirm current availability and accurate description |
| Events | Distinguish advertised plans from confirmed outcomes |
| Images, video, and logos | Record source, rights, consent, and safeguarding decision |
| Languages | Review complete English, Kiswahili, and Arabic content; verify Arabic RTL |
| Forms and privacy | Approve recipient, service, security, retention, and notice |
| Hosting and release | Obtain explicit authorization for deployment and public publication |

## Approval gates

- Scope and preflight review before implementation.
- Architecture and dependency approval before setup.
- Visual and interaction approval for primary page templates.
- School review of facts, translations, identity, and media before publication.
- Separate owner approval for remote push, deployment, and public release.

Unknown decisions remain open. Do not silently resolve them through assumptions.
