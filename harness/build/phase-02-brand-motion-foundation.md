# Phase 02 — Brand Tokens, Shared UI & Motion Primitives

**Requires Phase 01 + user approval.** Read `docs/03_BRAND_DESIGN.md`, `docs/04_MOTION_SYSTEM.md`, `docs/05_COMPONENT_REGISTRY.md`, `docs/09_MEDIA_SAFEGUARDING.md`.

## Scope

Implement a normal, school-focused MARKAZ ISLAMIC SCHOOLS homepage opening, one institutional header/nav shell, concise school introduction, design tokens, typography incl Arabic candidate, responsive layout primitives, skip link, one shadcn-based UI foundation, foundational Motion wrappers and reduced-motion behavior. Primary and Secondary remain ordinary Academics destinations, not the homepage theme. Prototype **only** a small set of selected P0/P1 component implementations for visual and technical review. Use a typography-led hero; unapproved school imagery stays local and opt-in.

## Acceptance

Appropriate EN/SW/AR structural views; no lost focus in nav/drawer; keyboard/touch parity; no horizontal overflow at 360–1440; reduced-motion immediate content; the homepage reads as a school introduction and does not center the educational levels. Compare tokens with actual reference posters; flag provisional codes. Test component licenses/versions and record any divergence.

## Out of scope

Full news/events archives, entire 14 pages, speculative decorative effects, new full component ecosystem, public preview deployment.

## Stop gate

Show working component sandbox with measurements and screenshots; wait for user approval before Phase 03.
