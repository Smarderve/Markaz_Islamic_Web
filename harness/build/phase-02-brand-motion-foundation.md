# Phase 02 — Brand Tokens, Shared UI & Motion Primitives

**Requires Phase 01 + user approval.** Read `docs/03_BRAND_DESIGN.md`, `docs/04_MOTION_SYSTEM.md`, `docs/05_COMPONENT_REGISTRY.md`, `docs/09_MEDIA_SAFEGUARDING.md`.

## Scope
Implement Markaz design tokens, typography incl Arabic candidate, responsive layout primitives, skip link, header/nav shell, one shadcn-based UI foundation, foundational Motion wrappers and reduced-motion behavior. Prototype **only** a small set of selected P0/P1 component implementations for visual and technical review. Use typography-based hero fallback, not unapproved school imagery.

## Acceptance
Appropriate EN/AR structural test shells; no lost focus in nav/drawer; pointer/touch/keyboard parity; no horizontal overflow at 360–1440; reduced-motion immediate content. Compare tokens with actual reference posters; flag provisional codes. Test component licenses/versions and record any divergence.

## Out of scope
News/events content, entire 14 pages, speculative decorative effects, new full component ecosystem, public preview deployment.

## Stop gate
Show working component sandbox with measurements and screenshots; wait for user approval before Phase 03.
