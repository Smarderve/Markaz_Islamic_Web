# Phase 06 — News, Events, Gallery & Local Search

**Requires approval.** Read `docs/02_PAGE_SPECIFICATIONS.md`, `docs/08_CONTENT_EVIDENCE.md`, `docs/09_MEDIA_SAFEGUARDING.md`, `docs/10_CONTENT_SCHEMAS.md`.

## Scope
News index/detail (deduplicated articles), Events index/detail (approved event records only; distinguish announcements from confirmed outcomes), Gallery (only approved photos/video; sophisticated empty state otherwise), local search over approved/prerendered pages. Filters, pagination, paths, search index and details work without a CMS/database.

## Acceptance
Event status not inferred from date; news announcements correctly archived; admissions status not inferred without current confirmation; multilingual filtering; keyboard and touch viewer; media manifest whitelist and caption proof; direct route reload; no unpublished content in search or bundles.

## Exclusions
Mass Instagram scraping, live updates, AI-generated stories, automatic permission assumption, newsletter, online student applications.

## Stop gate
Test links, index generation, source mapping and gallery behavior; request next phase approval.
