# Phase 05 — Eight Core Informational Pages

**Requires Phase 04 approval.** Read corresponding chapters in `docs/02_PAGE_SPECIFICATIONS.md`, current school content sources and publication matrix.

## Scope
About, History, Academics, Islamic Education, School Life, Achievements, Admissions, Contact (eight pages). Design distinct layouts per page; historic timeline, Arabic-safe quotes, semantic NECTA tables, anchored sections and transparent approval/status states. Keep current admissions/contact placeholders honest; do not enable pretend submission.

## Acceptance
Each responsive and keyboard navigable, distinct page composition, school attribution/source intact, no invented mission/founders/facilities/current fees, translated when reviewed; no unapproved public images. Event timelines use evidence-qualified dates.

## Exclusions
News archive/detail, Events archive/detail, Gallery, new backend or CRM, production deployment.

## Stop gate
Eight-page route QA report and user review, wait for Phase 06.
